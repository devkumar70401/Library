## 2. 📜 Where Custom Rules Can Be Added in Your Project

| File Location | Scope | What to Put There |
| :--- | :--- | :--- |
| **`GEMINI.md`** *(in workspace root)* | Project-Wide | Code style, project architecture rules, forbidden patterns |
| **`.agents/rules/*.md`** | Modular | Specialized rules for specific folders or languages |
| **`~/.gemini/antigravity-cli/rules.md`** | Global (All Projects) | Personal preferences across all sessions |
